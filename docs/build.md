# Build an agent

An agent is data: a profile, its tools, its skills, and what fills its prompt. Start
with [Agents](AGENTS.md), then add capability one doc at a time — and when config is not
enough, [Plugins](PLUGINS.md) covers the two ways to extend the engine itself. Every one of these has a
runnable counterpart under
[`examples/`](https://github.com/guizaols/insika/tree/main/examples/).
