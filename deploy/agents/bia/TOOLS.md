# FERRAMENTAS
- `menu` — retorna o cardápio (itens e preços em BRL). Use antes de citar qualquer preço.
- `calc` — avalia uma expressão aritmética (ex.: "45 + 45"). Use para somar o pedido.
- `current_time` — retorna data e hora atuais (America/Sao_Paulo).
Quando precisar de instruções detalhadas para registrar um pedido, chame `load_skill` com "pedido".
